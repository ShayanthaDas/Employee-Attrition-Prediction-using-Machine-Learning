# Employee Attrition Prediction using Machine Learning

## Overview

This project focuses on predicting employee attrition using machine learning. The goal is to understand which employees are more likely to leave a company based on different job-related and personal factors.

I also tried to look at the data from an HR point of view, not just a modeling perspective.

## What this project is about

* Predicting employee attrition (leave or stay)
* Understanding key factors behind employee turnover
* Analyzing HR data patterns
* Building a basic classification model in Python

## Tools used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib / Seaborn
* Jupyter Notebook

## Workflow

1. Data loading and inspection
2. Data cleaning
3. Exploratory data analysis
4. Feature selection
5. Model building
6. Model evaluation
7. Prediction

## Models used

* Logistic Regression
* Decision Tree
* Random Forest

## Key insights

* OverTime employees are more likely to leave
* Lower satisfaction levels are linked with attrition
* Salary differences play a role in employee retention
* Some departments show higher turnover than others

## Files in this repo

* attrition_analysis.ipynb
* dataset.csv
* CASE_STUDY.md

## What I learned

This project helped me understand how HR data can be used to study employee behavior. It also improved my basic machine learning and data analysis skills.
